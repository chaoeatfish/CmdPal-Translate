命令面板翻译插件 · 使用说明

给 Windows 命令面板新增的翻译功能，与你原有的 Everything 插件并存，两者互不影响。

最常用的一步

按 Win + Alt + Space 打开命令面板 → 输入 tr 你好 → 看到译文 → 按 Enter 复制。

当前状态：安装包已装好，但命令面板还没加载它
扩展包（0.0.3.0）已成功安装到 Windows。但本机命令面板在启动扩展时返回「拒绝访问」（错误码 0x80070005）——这是 Windows 10 对自签名侧载扩展的 COM 激活限制。你原有的 Everything 扩展是商店签名的，不受影响，目前仍正常工作。
  1. 重启一次电脑（旁加载与开发者模式是刚开启的，需要重新登录才完全生效）。
  2. 打开命令面板，输入 Reload → 选 Reload Command Palette extensions。
  3. 在「设置 → 扩展」里看到「翻译」，输入 tr 你好 出现译文，即成功。
如果重启后仍看不到「翻译」，说明这台机器的策略无法激活侧载扩展；可按第五节卸载，Everything 插件完全不受影响。

一、开始使用

  1. 打开命令面板（默认快捷键 Win+Alt+Space）。
  2. 输入 tr 加上要翻译的文字，例如 tr 水土保持方案 或 tr soil conservation。
  3. 稍等约半秒，结果里出现译文。按 Enter 直接复制译文到剪贴板。
  4. 粘贴到任何地方即可。
不用申请账号、不用填密钥：默认使用免费翻译服务，装好即可用。文本会发送到第三方服务，请勿翻译敏感/机密内容；如需更私密或更大额度，见第四节。

二、常用写法

输入效果
tr hello自动判源，中文 ⇄ 英文互译
翻译 你好中文前缀，效果相同
tr >en 你好 或 tr 你好 >en强制译成英文
tr >zh hello强制译成中文
打开「翻译」后再输入进入翻译页，整段文字直接翻译，不需要前缀
report.pdf（无前缀）不会出现翻译结果，Everything 搜索照旧

三、结果里能做什么

  • 按 Enter：复制译文（会提示已复制）。
  • 右下角命令栏：复制译文 / 复制原文 / 交换语言方向 / 查看详情（长文本）/ 翻译剪贴板 / 导入密钥 / 设置。
  • 结果下方小字显示：语言方向、使用的引擎、耗时。
  • 较长的内容会显示「查看详情」，用 Markdown 页面完整展示。

说明：插件只在你输入前缀时才出现，不占用全局快捷键，也不会改动 Everything 插件的结果、排序或设置。

四、设置（可选）

命令面板 → 打开「设置」→「扩展」列表 → 选择「翻译」。常用项：

设置项作用默认
翻译引擎自动 / 免费（免密钥）/ Azure（需密钥）自动
源语言 / 目标语言固定方向；自动时按文字判定自动识别
触发前缀可改成自己习惯的字母，逗号分隔tr,翻译
启用首页内联结果关掉后只在「翻译」页里出结果开
防抖 / 超时 / 缓存输入停顿多久才翻译、超时秒数、译文缓存时间300ms / 5s / 60min

想用自己的 Azure 翻译服务（可选）

  1. 在 Azure 门户创建「翻译」资源，复制密钥。
  2. 复制密钥到剪贴板。
  3. 打开「翻译」页 → 右下角命令栏 → 「从剪贴板导入 API 密钥」。
  4. 设置里把「翻译引擎」改为「Azure」，并按需填写端点与服务区域。

密钥以 Windows DPAPI 加密保存在本机，不会写进设置文件、不会出现在日志里。

五、常见问题

现象处理
列表里看不到「翻译」在命令面板输入 Reload，选择「Reload Command Palette extensions」；确认「设置 → 扩展」里已启用。
显示「尚未配置翻译服务」把「翻译引擎」设为「自动」或「免费」；检查网络是否能访问外网。
显示「翻译失败」多为网络不通或免费服务当日额度用完；稍后重试，或改用 Azure 引擎。
输入英文文件名也冒出翻译检查「触发前缀」是否被误改；正常情况只有带前缀才出现。
Everything 结果变少/排序变了本插件不参与无前缀查询，也不会写 Everything 的设置；可关闭「启用首页内联结果」再对比。
想卸载Windows「设置 → 应用」里卸载「翻译」扩展；或在 PowerShell 执行 Get-AppxPackage *Translate* | Remove-AppxPackage。
隐私提示：默认的免费引擎会把你输入的文字发送到 MyMemory 公共翻译接口；Azure 引擎发送到你配置的端点。请勿用于机密内容。插件不会读取剪贴板，除非你主动点「翻译剪贴板」或「导入密钥」。

六、技术信息（供排查用）

  • 扩展包：Microsoft.CmdPal.Ext.Translate，独立 MSIX，与 Everything 扩展进程隔离。
  • 本机命令面板：PowerToys 0.102.3101.0 / Command Palette 0.13.13096.0。
  • 扩展 SDK 版本与本机 Everything 扩展一致（0.9.260303001）。
  • 设置文件：%LOCALAPPDATA%\Microsoft\CmdPal\translate.settings.json；密钥文件：translate.credential.bin。
  • 工程与脚本目录：TranslateCmdPal/；验证清单见 repo-integration/VALIDATION.md。
